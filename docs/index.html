Noml Icons.

The icon set of the Noml suite: geometric monoline glyphs drawn in the Noml Sans design DNA, with superellipse squircle rounds, flat butt terminals, and beveled apexes. Free, MIT-licensed React components.

417 icons MIT license

Usage

Every icon is a tree-shakeable React component that takes only a className. Size and color come from your CSS: each glyph is drawn on a 24 unit grid in currentColor, so it follows the text color and scales crisply. Click any icon below to copy its import.

import { SearchIcon, HeartIcon } from "noml-icons";

export function Toolbar() {
  return (
    <div className="toolbar">
      <SearchIcon className="icon" />
      <HeartIcon className="icon" />
    </div>
  );
}

/* icons inherit color and size from CSS */
.icon { width: 20px; height: 20px; color: inherit; }
